# Cepha K-space concept template v1

## Purpose

This snapshot preserves the current Cepha visual language:

- illuminated saddle surface;
- cyan and magenta network anchors;
- concept nodes and connecting path;
- gold replay cursor;
- pointer, touch, wheel, and keyboard interaction;
- reduced-motion support;
- evidence-console layout and browser-side proof interaction.

The snapshot is outside `docs`, so Cloudflare Workers does not publish it.
`wrangler.toml` deploys only `./docs`.

## Runnable fallback

The preserved treatment can be exercised through:

- repository path: `docs/cepha-k-space-concept/`;
- local preview: `http://127.0.0.1:8787/cepha-k-space-concept/`;
- existing Worker path after the next approved deployment:
  `https://leap2026.sbay.sa/cepha-k-space-concept/`.

The runnable copy changes only the surrounding labels and status language to
make the non-evidentiary boundary explicit. The immutable source snapshot and
its hashes remain in this directory.

## Evidence boundary

This is a **conceptual visual template**, not model evidence. The saddle,
branches, anchors, motion, depth, and protrusions must never be described as
measured curvature, a neural manifold, model topology, activation geometry, or
training impact unless a separate measurement artifact establishes that exact
claim.

The sample JSON preserves the renderer contract and deterministic demonstration
data only. It is not an authentic zero checkpoint, trained-model activation
capture, or zero-versus-trained comparison. Reuse the visual treatment, but
replace the data adapter and all evidence wording for each measured deployment.

## Snapshot contents

- `source/docs/k-space.js`: renderer and interaction behavior.
- `source/docs/index.snapshot.html`: page markup containing the original scene.
- `source/docs/styles.snapshot.css`: complete style context for the scene.
- `source/docs/assets/evidence/cns-k-space-public.sample.json`: sample renderer
  input.
- `source/scripts/build-k-space-public.snapshot.mjs`: original sample-artifact
  adapter.
- `SNAPSHOT-MANIFEST.json`: byte lengths, SHA-256 identities, and use policy.

Do not copy the original scientific wording into a public release. A measured
engineering graph must use its own artifact schema, legend, units, formulas,
limitations, and independently recomputable hashes.
